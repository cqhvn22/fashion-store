# Cấu hình chuyển khoản qua PayOS

1. Trong `.env` ở thư mục gốc, điền `PAYOS_CLIENT_ID`, `PAYOS_API_KEY`, `PAYOS_CHECKSUM_KEY` từ kênh thanh toán PayOS. Giữ các khóa này ở backend, không đưa vào biến `VITE_*` hoặc Git.
2. Đặt `PAYOS_RETURN_URL` và `PAYOS_CANCEL_URL` trỏ tới frontend đang chạy (mặc định `http://localhost:3000/payment/success` và `http://localhost:3000/payment/cancel`). Backend tự thêm `orderId` vào URL cho từng đơn.
3. Đăng ký webhook trực tiếp tại `https://<tên-miền-backend>/api/v1/payments/payos/webhook` nếu API Gateway có địa chỉ HTTPS công khai. Nếu chỉ có PHP hosting, tải [webhook.php](../../webhook.php) lên host và đăng ký URL công khai của file, ví dụ `https://<tên-miền-host>/webhook.php`. Trong file, thay `YOUR_BACKEND_DOMAIN` bằng tên miền HTTPS công khai của API Gateway, hoặc đặt biến môi trường `FASHIONHUB_PAYOS_WEBHOOK_TARGET` trên host. PHP phải bật cURL. File chỉ chuyển tiếp JSON; Order service Quarkus vẫn xác minh chữ ký PayOS và cập nhật đơn hàng.
4. Sau khi sửa `.env`, tạo lại container `order-service` để nạp biến môi trường mới: `docker compose -p fashion-codex --env-file .env -f infrastructure/docker/compose.yaml up -d --no-deps --no-build --force-recreate order-service`. Chỉ sửa file `.env` hoặc khởi động lại tiến trình Java sẽ không đổi biến môi trường của container đã tạo. Khách chọn **Chuyển khoản ngân hàng qua PayOS** tại checkout để mở popup QR ngay trên web. Popup tự kiểm tra trạng thái mỗi 5 giây khi đang mở; khách cũng có thể mở lại từ trang chi tiết đơn nếu chưa thanh toán. Giao diện kiểm tra trạng thái đơn từ backend; tham số trên URL quay về không được dùng để xác nhận đã thanh toán. Nếu thiếu khóa, đơn không được tạo và giao diện báo PayOS chưa cấu hình.

`PAYOS_API_URL` mặc định là `https://api-merchant.payos.vn`. Chỉ đổi khi PayOS cung cấp endpoint khác. Mỗi link thanh toán hết hạn sau 15 phút; đơn chờ thanh toán được đối soát và hủy khi link hết hạn. Xem [tài liệu tạo link](https://payos.vn/docs/api/) và [Return URL](https://payos.vn/docs/du-lieu-tra-ve/return-url/).

**Lưu ý:** PHP hosting không thể chuyển tiếp tới `localhost:8080` trên máy cá nhân. Backend phải có địa chỉ HTTPS công khai mà hosting truy cập được (triển khai trên máy chủ hoặc dùng tunnel trong môi trường thử). Không trả HTTP 200 nếu backend chưa nhận webhook; khi đó đơn sẽ không được cập nhật.
